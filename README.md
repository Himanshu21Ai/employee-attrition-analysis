# Employee Attrition Analysis and Prediction

## Project Overview
This project analyses employee attrition to understand patterns associated with employees leaving an organisation. It uses Python for data analysis, visualisation, and machine learning-based attrition prediction.

## Objectives
- Explore employee data and identify attrition patterns.
- Analyse the relationship between attrition and factors such as salary, department, job satisfaction, and work-life balance.
- Visualise key findings using Python.
- Build and compare machine learning classification models.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook (if applicable)

## Project Workflow

### 1. Data Exploration
- Inspected dataset structure, columns, and data types.
- Examined summary statistics.
- Checked for missing values and duplicate records.

### 2. Exploratory Data Analysis
- Analysed employee attrition counts.
- Compared attrition across departments.
- Investigated monthly income, job satisfaction, and work-life balance.
- Created visualisations to explore employee patterns.

### 3. Data Preprocessing
- Encoded the target variable.
- Applied one-hot encoding to selected categorical variables.
- Split the dataset into training and testing sets.
- Applied feature scaling.

### 4. Machine Learning
Implemented and compared:
- Logistic Regression
- Random Forest Classifier

### 5. Model Evaluation
Evaluated the models using:
- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
